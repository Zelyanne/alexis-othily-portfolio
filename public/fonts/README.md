# Portfolio typography

Outfit is self-hosted from the official Google Fonts source. Its SIL Open Font
License is included in `OFL-Outfit.txt`.

- Font: https://github.com/google/fonts/blob/main/ofl/outfit/Outfit%5Bwght%5D.ttf
- License: https://github.com/google/fonts/blob/main/ofl/outfit/OFL.txt
- Downloaded: November 2, 2026.

Outfit is a geometric substitute, **not Brodine**. No Brodine binary is bundled.
The intended Brodine family is published by Artiveko and listed on MyFonts:
https://www.myfonts.com/collections/brodine-font-artiveko

A licensed Brodine webfont kit is still needed for the exact requested typeface.
